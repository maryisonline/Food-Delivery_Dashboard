Protótipo de dashboard com dados fictícios obtidos no Kaggle. 
O projeto simula uma empresa de Delivery, que visa informações voltadas para a quantidade de pedidos, faturamento e entregas.

# Pipeline de Dados

1. **CSV**
   Arquivo de origem com os dados brutos.

2. **PostgreSQL**
   Ingestão e armazenamento estruturado dos dados (staging/banco relacional).

3. **Power BI**
   Conexão com o banco de dados para consumo dos dados.

4. **Modelo de Exibição**
   Modelagem das tabelas (relacionamentos, esquema estrela, etc.) para análise.

5. **ETL em DAX**
   Transformações e cálculos finais via medidas/colunas calculadas em DAX.

Este protótipo conta apenas com a tratativa no PBI, com máximo ajustes em "Modelos de Exibição".
